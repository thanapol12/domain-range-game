บทที่ 1: ความหมายของความสัมพันธ์ โดเมน และเรนจ์

ในโลกคณิตศาสตร์ "ความสัมพันธ์" (Relation) คือ กลุ่มของสิ่งของที่มาจับคู่กัน หรือเขียนให้อยู่ในรูปของ คู่อันดับ (x, y)

โดเมน (Domain: D)

กลุ่มของ สมาชิกตัวหน้า (ค่า x) หรือข้อมูลนำเข้า (Inputs) ทั้งหมดที่เป็นไปได้

เรนจ์ (Range: R)

กลุ่มของ สมาชิกตัวหลัง (ค่า y) หรือผลลัพธ์ (Outputs) ทั้งหมดที่เกิดขึ้นได้จริง

💡 จำง่ายๆ: โดเมน = ตัวหน้า (แกนนอน x) | เรนจ์ = ตัวหลัง (แกนตั้ง y)

บทที่ 2: วิธีหาจากคู่อันดับและแผนภาพลูกศร

เมื่อเจอความสัมพันธ์ที่เป็นเซตของคู่ระเบียบ ให้ดึงค่าออกมากดใส่เซต:

ตัวอย่าง: R = { (1, 5), (3, 7), (4, 7) }
  • โดเมน = ตัวหน้า = { 1, 3, 4 }
  • เรนจ์ = ตัวหลัง = { 5, 7 } (เลข 7 ซ้ำกัน เขียนแค่ตัวเดียว)

🧙‍♂️ ทดลองร่ายเวท: กำหนด R = { (2, 8), (5, 9), (6, 8) } โดเมนคืออะไร?

บทที่ 3: วิธีหาจากกราฟระบบพิกัดฉาก

เมื่อส่องดูศัตรูผ่านแผนที่แกนพิกัดฉาก:

  • หาโดเมน (แกน X): ดูขอบเขตของกราฟจาก ซ้ายสุด ไปยัง ขวาสุด
  • หาเรนจ์ (แกน Y): ดูขอบเขตของกราฟจาก ล่างสุด ไปยัง บนสุด
จุดทึบ (Closed Circle): รวมจุดปลายนั้นด้วย ใช้สัญลักษณ์ [ หรือ ] หรือ ≤
จุดโปร่ง (Open Circle): ไม่รวมจุดปลายนั้น ใช้สัญลักษณ์ ( หรือ ) หรือ <
ตัวอย่าง: เส้นกราฟเชื่อมจุดทึบ (-2, 1) และ (3, 5)
โดเมน = [-2, 3] (คือตั้งแต่ x = -2 ถึง 3) | เรนจ์ = [1, 5] (คือตั้งแต่ y = 1 ถึง 5)

บทที่ 4: วิธีหาจากเงื่อนไขของฟังก์ชัน (พีชคณิต)

หากวิหารด่านสุดท้ายบอกเงื่อนไขเป็นสมการ จงระวังข้อห้ามเหล็ก 2 ประการ:

⚠️ ตัวหารห้ามเป็น 0

เช่น f(x) = 5 / (x - 2)
ตัวส่วน x - 2 ≠ 0 ดังนั้น x ≠ 2

⚠️ ในรากที่สองห้ามติดลบ

เช่น f(x) = √(x - 3)
ข้างในรูท x - 3 ≥ 0 ดังนั้น x ≥ 3

หากจดจำตำราเรียบร้อยแล้ว จงกดปุ่มถัดไปเพื่อเริ่มทดสอบความกล้าได้เลย!

📘 บันทึกตำราเวทโดเมนและเรนจ์

1. คู่อันดับ R = { (x, y) }

  • โดเมน (D): ดึงสมาชิกตัวหน้า (x) ทั้งหมดออกมาเขียนเป็นเซต เช่น { 1, 3 }
  • เรนจ์ (R): ดึงสมาชิกตัวหลัง (y) ทั้งหมดออกมาเขียนเป็นเซต เช่น { 2, 4 }
  • ห้ามใส่ตัวซ้ำในเซต และเขียนเรียงลำดับเสมอ!

2. การหาจากกราฟ

  • โดเมน: กวาดสายตาทางแนวนอน (ซ้าย → ขวา) ขอบเขตของค่า x
  • เรนจ์: กวาดสายตาทางแนวตั้ง (ล่าง → บน) ขอบเขตของค่า y
  • จุดวงทึบ [ ] คือ รวมจุดปลายนั้นด้วย
  • จุดวงโปร่ง ( ) คือ ไม่รวมจุดปลายนั้น

3. การหาจากสมการฟังก์ชัน

  • มีเศษส่วน: ตัวส่วน ≠ 0 (หาตัวเลขที่ทำให้ตัวส่วนเป็น 0 แล้วตัดออก)
  • มีรากที่สอง (Square Root): พจน์ในเครื่องหมายรูท ≥ 0 ตั้งอุปสรรคแก้ไขเพื่อหาช่วง x
  • ยกกำลังสอง $x^2$: เนื่องจาก $x^2 \ge 0$ เสมอ ดังนั้น $x^2 + c \ge c$ เสมอ
